# Stage 4

## Advanced Hillclimb

With "--algorithm=hc" we have a really simple hillclimb.  Let's
add a more sophisticated hillclimb.  Two that come to mind are
tabu search and WalkSAT.  But I want you to pick the one you
think is best.

Search the litature and select the best hillclimb-like algorithm
which is not too difficult to add to this code base. 

## Command Line Parameters

No new parameters.

--algorithm=<string> -a <string>
Add a short name for the algorithm you select.

If your selected algorithm needs parameters via

--alg-params (or -p)

document what they are.

Be sure to update --help (-h)
